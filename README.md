# 光の干渉:ヤングの実験(WebAR教材)

高校物理の授業で、生徒が iPad(Safari)で使う教材です。
机にカメラを向けると、レーザー → 二重スリット → スクリーン の模型が机の上に現れ、
波長・スリット間隔・距離を変えながら干渉縞を観察・測定できます。
カメラが使えない端末では「ARなし」の3D表示で、同じ機能がそのまま使えます。

- 外部通信なし(CDN・Webフォント・解析なし)、ログインなし、データ保存・送信なし
- ビルド不要の静的サイト(HTML/CSS/JSを置くだけ)

---

## 1. 何ができるか

| 機能 | 内容 |
|---|---|
| 観察モード | 波長 λ(380〜750 nm)、スリット間隔 d(0.10〜1.00 mm)、距離 L(0.50〜2.00 m)をスライダーで変更。スクリーンの縞がリアルタイムに変わる |
| 白色光 | 380〜750 nm を重ねて表示。中央が白、周囲に色づいた縞 |
| Δx = Lλ/d 表示 | 計算値の表示オン/オフ(スクリーン上の黄色い目印が mΔx の位置) |
| 点Pの調査 | スクリーンをタップ → S1P, S2P の光線と、経路差「Δ = ○.○○ λ」、明線/暗線/中間の判定 |
| 波面 | スリット〜スクリーン間の水平面に2つの円形波の重ね合わせをアニメ表示(**模式図**。表示上の波長と d は λ, d に比例) |
| 測定モード | 波長未知のレーザー(450〜680 nm、開くたびにランダム)。定規またはマーカーA/Bで暗線の距離を測り、生徒が Δx → λ = dΔx/L を計算して入力 → 誤差%を表示。試行の記録表付き(このページを開いている間だけ) |

### 縮尺について(重要)
実際の縞の間隔 Δx = Lλ/d は数 mm しかなく、そのままでは AR で見えません。そこで
- スクリーンは **拡大表示**(実寸 1 mm = 模型 10 mm)
- スリット間隔は **誇張**して描画(波面・スリット板の見た目だけ)

しています。AR の大きさ(SLAM のスケール)は実寸ではないため、**数値は必ずスクリーン下の定規(実寸 mm)で読み取る**ようにしてあります。定規の値と、計算式(経路差の厳密式 Δ = √(L²+(y+d/2)²) − √(L²+(y−d/2)²))の値は一致します。

## 2. 公開方法(静的ファイルを置くだけ)

このフォルダ(`young-double-slit/`)の中身をそのまま Web サーバーに置けば完了です。サーバー側のプログラムは不要です。

- **カメラを使うため、公開URLは必ず `https://` にしてください。** GitHub Pages、Cloudflare Pages、Netlify、学校のWebサーバー(HTTPS)などが使えます。
- `http://` だと ARは開始できませんが、「ARなし」モードは動きます。
- 現在の公開先: GitHub Pages `https://tsukumo99-0629.github.io/young-double-slit/`(リポジトリ `Tsukumo99-0629/young-double-slit` の main ブランチ直下)。作成者の個人アカウントなので、異動・交代の際は学校のサーバーや後任のアカウントへこのフォルダごと移し、生徒に配るURLも更新してください。
- 置くのは `index.html`, `css/`, `js/`, `vendor/` です(`test/` と `package.json` は不要。置いても害はありません)。

### パソコンで試す(ローカル起動)
ターミナルでこのフォルダに移動して:

```
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開く。(`localhost` はカメラ使用可。iPad から `http://パソコンのIP:8080` で開いても、httpなのでARは開始できません。ARの実機確認は https の公開先で行ってください。)

### 物理計算のテスト
Node.js(v18以上)で:

```
node --test test/
```

## 3. 授業での使い方(例)

1. 生徒は iPad の Safari で URL を開く(QRコードを配ると楽です)。
2. 「ARで始める」→ カメラとモーションセンサーの許可で「許可」。
3. 机にカメラを向けてゆっくり動かし、「机の上をタップして装置を置いてください」と出たら机をタップ。
4. **観察**: λ を変えると色と縞の間隔が、d を変えると間隔が、L を変えるとスクリーンが実際に動き間隔が変わることを確認。「Δx = Lλ/d を表示」で計算値と見比べる。
5. スクリーンの点をタップして経路差を調べ、「Δ = mλ → 明線」「Δ = (m+½)λ → 暗線」を確かめる。
6. **測定**タブ: 波長未知のレーザーで、暗線2本にマーカーA/Bを置き、距離と縞の数 n から Δx を求め、λ = dΔx/L を計算して入力 → 誤差を確認。d や L を変えて何度か測定する。

- 「置き直す」: 装置の位置を変えたいとき
- 「模型の大きさ」: AR で大きすぎる/小さすぎるとき
- パネルは「操作パネル」の見出しをタップで折りたたみ(AR の視界を広げられます)

## 4. iPad で動かないとき(確認項目)

| 症状 | 確認すること |
|---|---|
| 「ARで始める」を押すとエラーになる | 画面に原因が日本語で出ます。「ARなしモードに切り替える」ボタンで授業は続行できます |
| カメラが許可されない | iPad の「設定 > Safari > カメラ」を「確認」または「許可」に。または Safari のアドレスバー左の「aA」→「Webサイトの設定」→ カメラ「許可」。変更後はページを再読み込み |
| 傾き(モーション)が許可されない | 「設定 > Safari > 詳細」または「aA > Webサイトの設定」で「モーションと画面の向きへのアクセス」を許可。再読み込み。いったん「拒否」すると同じタブでは再度聞かれないので、Safari を完全に閉じて開き直す |
| 黒い画面のまま | 他のアプリ(FaceTime等)がカメラを使用中でないか。iPad を再起動 |
| `http://` で開いている | カメラは `https://` のみ。URLを確認 |
| 学校のiPad(MDM管理) | 管理者がカメラ/Safari/モーションセンサーを制限していることがあります。構成プロファイルで Safari と カメラが許可されているか、校内フィルタが公開URL(と、そのサーバー内の `vendor/xr/` 以下のファイル)をブロックしていないか確認 |
| 装置が揺れる/ずれる | 明るい場所で、模様や物のある机で。真っ白な机は苦手です。端末をゆっくり動かす |
| 装置が遠すぎる/近すぎる | 「模型の大きさ」スライダーで調整、「置き直す」でやり直し |
| 古い iPad / iOS | Safari が古いと動きません。その場合は「ARなし」を使用 |

どうしても AR が動かない場合でも、「ARなしで始める」なら全機能が使えます(1本指で回転、2本指でズーム)。

## 5. 8th Wall のサポート状況と、エンジンの差し替え方

- このアプリの AR 部分は 8th Wall の **XR Engine バイナリ**(`@8thwall/engine-binary@1.0.0`)を使っています。ログインやアプリキーは不要です。
- 8th Wall のホスト型プラットフォームは **2026-02-28 に終了**、ホスティングは **2027-02-28 に停止**予定と案内されています。このアプリは エンジンのファイルを `vendor/xr/` に**同梱**(無改変)しているので、サーバーさえあれば 8th Wall 側のサービス終了後も動き続けます。ただし今後エンジンの更新・サポートは期待できません(ライセンス上も無保証)。将来 iOS の更新で動かなくなる可能性があります。
- 8th Wall に触っているのは **`js/ar.js` だけ**です。将来エンジンを変えるときは、`js/ar.js` を同じ公開インターフェース(ファイル冒頭のコメント参照: `isEngineLoaded / requestSensors / start / stop`)を持つ別実装に置き換え、`index.html` の `vendor/xr/xr.js` の行を差し替えれば、他のファイルは変更不要です。
- 3D表示は three.js **r159**(グローバル版 `three.min.js`)を同梱。8th Wall エンジンが `window.THREE` を使うため、バージョンを上げる場合は動作確認が必要です(r160 以降はグローバル版が廃止されています)。

### vendor/ を「改変しない」こと
`vendor/xr/` のファイルは、ライセンス上、元の形のまま配布する必要があります。**編集・整形・圧縮し直し・ファイルの一部削除をしないでください**(`xr-face.js` や `resources/` 内の顔認識用ファイルも、そのまま残してください)。

```
test/physics.test.js  物理計算のテスト
```
